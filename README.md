# Customer Shopping Behavior Analysis

**End-to-End Data Analytics Project | Python | SQL | Power BI**

**Author:** Narendra Kompala

## Project Overview

This project analyzes customer shopping behavior using 3,900 purchase records to identify purchasing patterns, product preferences, customer segments, discount usage, and subscription behavior.

The objective is to generate actionable business insights that can help improve customer engagement, marketing effectiveness, and retail business decisions.

## Business Problem

A retail company wants to understand how customer demographics, product preferences, discounts, shipping methods, reviews, and subscription status relate to purchasing behavior and purchase revenue.

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL / PostgreSQL
- Power BI

## Project Workflow

1. Data Understanding
2. Data Cleaning and Preparation using Python
3. Exploratory Data Analysis (EDA)
4. Business Analysis using SQL
5. Interactive Dashboard Development using Power BI
6. Business Insights and Recommendations

## Project Deliverables

### 1. Python – Data Cleaning and EDA
- Missing value treatment
- Duplicate checks
- Column standardization
- Feature engineering
- Exploratory data analysis
- Data visualization

### 2. SQL – Business Analysis

Analyzed 10 business questions:

- Revenue by gender
- High-spending discount users
- Top 5 products by rating
- Shipping type comparison
- Subscribers vs non-subscribers
- Discount dependency analysis
- Customer segmentation
- Top 3 products per category
- Repeat buyer and subscription analysis
- Revenue by age group

### 3. Power BI – Interactive Dashboard

Dashboard KPIs:
- Total purchase records
- Total purchase revenue
- Average purchase amount
- Average review rating

Dashboard visualizations:
- Customer distribution by subscription status
- Revenue by gender
- Revenue by category
- Revenue by age group
- Top 10 products by revenue

Interactive filters:
- Subscription status
- Gender
- Product category
- Shipping type
- Payment method

### 4. Key Dataset Findings

- Total purchase records: 3,900
- Total purchase amount: $233,081
- Average purchase amount: $59.76
- Missing review ratings: 37 before cleaning

### 5. Repository Structure

- `dataset/` – Original dataset

- `sql/` – SQL business queries
- `powerbi/` – Power BI dashboard
- `documentation/` – Project overview and analysis report
- `screenshots/` – Dashboard preview

## How to Run

1. Clone this repository.
2. Install the required Python libraries using `pip install -r requirements.txt`.
3. Open the notebook in Jupyter Notebook.
4. Update the database connection settings before running SQL integration, if required.
5. Open the Power BI `.pbix` file using Power BI Desktop.
